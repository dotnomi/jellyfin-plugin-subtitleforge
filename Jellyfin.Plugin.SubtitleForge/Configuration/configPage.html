ASS/SSA and forced

For anime: dialogue and lyrics as track "[SF] Text" that follows the uniform style. Signs/typesetting are dropped; the original ASS track stays selectable. Runs with the OCR task.
If there is an audio track in a wanted language (e.g. a German dub) but no forced subtitle: signs and songs from the ASS track become a forced track, otherwise a subtitle marked "foreign parts only" is downloaded. Only on an exact match (hash or same release), because forced subtitles cannot be checked against the audio.

Sync (check against the audio)

Fixes offset, frame rate and cut differences; rejects subtitles that do not fit the audio. The first analysis of a movie takes 20 seconds to a few minutes, depending on the CPU.
Applies to the task "Check and fix subtitle sync". The original is kept as *.srt.orig.

Speech recognition (Whisper)

Generates subtitles from an audio track: manually from the overview or the SubtitleForge entry on a movie/episode/season/series, optionally automatically. The model is downloaded on first use. Result: track "[SF] [AI] Whisper".

Applies to all movies/series without a tag. Switch single series/movies with the tag whisper:auto or whisper:off in the metadata editor. Off by default: Whisper then only runs when started manually. Automatically it can cost many hours of computing time on small CPUs.
After the nightly download task: episodes without a subtitle for the number of days set below get a Whisper subtitle, at most as many per run as set (oldest gaps first). Respects the time window.
Without a fitting GPU or Vulkan driver the CPU is used automatically. Needed on the server: the packages libvulkan1 and mesa-vulkan-drivers (AMD/Intel), and access for Jellyfin to /dev/dri (as for hardware transcoding). Takes effect after restarting Jellyfin. If the driver crashes, the job continues on the CPU.
If no subtitle is downloaded, the plugin translates an existing text subtitle of another language offline (preferably the official track, e.g. German → English). The timing stays exact, there are no recognition errors. Whisper is only considered after that. Result: track "[SF] [AI] Translated de-en".
If there is no audio track in the wanted language, the best recognised audio track is transcribed and translated locally: German↔English (Opus-MT), Japanese↔English (FuguMT), Japanese↔German via English. Models (about 110–150 MB per direction) are downloaded on first use. Quality: good for German↔English, for Japanese rather for understanding.
