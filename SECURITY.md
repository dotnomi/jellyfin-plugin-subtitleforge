# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include what you found, how to reproduce it and which version you use. You will get an answer as soon as possible;
fixes are released as a new plugin version and mentioned in the changelog.

## Supported versions

Only the latest release gets security fixes. Update through the plugin repository in Jellyfin.
